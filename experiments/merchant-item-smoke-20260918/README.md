# Merchant-item isolated smoke

This archive contains the frozen one-shot integration harness for the source-bound merchant relic and potion candidate. The allocation uses one fresh Defect A10 seed, forbids retries, fitting, model selection, and automatic deployment, and runs only after the active continuous-training batch reaches a clean boundary. The handoff resumes the persistent MiniMax goal after either success or failure.

At this commit the smoke is prepared and queued; no game has started. Runtime results are archived separately after the one-shot service reaches a terminal state.
